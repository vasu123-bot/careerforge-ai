# CareerForge AI - Software Requirements Specification (SRS)

## Project Name
CareerForge AI

## Version
1.0

## Project Goal
CareerForge AI is an AI-powered career platform that helps users improve their resumes, analyze ATS scores, prepare for interviews, match jobs, and identify skill gaps.

## Target Users
- Students
- Fresh Graduates
- Working Professionals
- Job Seekers

## Main Features
- User Authentication
- Resume Upload
- Resume Analysis
- ATS Score
- AI Suggestions
- Job Description Matching
- Interview Preparation
- Skill Gap Analysis
- Dashboard
- User Profile

## Tech Stack

### Frontend

### Backend
- Python
